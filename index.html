Dépannage & Support LAN

Prise en main à distance ultra-rapide (RDP & MSRA)

1 Configuration du PC d'administration Requis

Pour que le bouton Assister le collègue (MSRA) fonctionne depuis ton navigateur, tu dois déclarer le protocole msra:// dans le registre de ton PC admin.

Après le téléchargement : double-clic sur le fichier → accepter la fusion dans le registre → redémarrer le navigateur.

2 Protocole rdp:// Optionnel

Le bouton Prise en main (RDP) télécharge un fichier .rdp qui s'ouvre automatiquement avec mstsc.exe — aucune configuration requise, c'est la méthode la plus fiable.

Si tu veux néanmoins un vrai lien rdp:// (comme pour MSRA), fusionne ce second fichier .reg sur le PC d'administration.

3 Activer RDP & MSRA sur les PC cibles Requis

Exécute ce script dans PowerShell en tant qu'administrateur sur chaque machine à dépanner. Il active RDP, MSRA, le pare-feu et force le démarrage du service.

Activation_RDP_MSRA.ps1 
# ============================================
# Activation RDP + Assistance à distance (MSRA)
# À exécuter en PowerShell ADMIN sur le PC cible
# ============================================

# 1. Activer le Bureau à distance et l'Assistance à distance
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name "fDenyTSConnections" -Value 0
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name "fAllowToGetHelp" -Value 1

# 2. Activer les règles de pare-feu
Enable-NetFirewallRule -DisplayGroup "Bureau à distance"
Enable-NetFirewallRule -DisplayGroup "Assistance à distance"

# 3. Forcer le démarrage du service Terminal Server
Set-Service TermService -StartupType Automatic
Start-Service TermService

# 4. Vérification rapide
Write-Host ""
Write-Host "=== Vérifications ===" -ForegroundColor Cyan
$ts = Get-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server'
Write-Host "fDenyTSConnections : $($ts.fDenyTSConnections) (attendu: 0)"
Write-Host "fAllowToGetHelp    : $($ts.fAllowToGetHelp) (attendu: 1)"
Write-Host "TermService        : $((Get-Service TermService).Status) (attendu: Running)"
$port = netstat -an | Select-String ":3389.*LISTENING"
if ($port) { Write-Host "Port 3389          : EN ÉCOUTE ✅" -ForegroundColor Green }
else       { Write-Host "Port 3389          : FERMÉ ❌ (redémarre la machine)" -ForegroundColor Red }

Write-Host ""
Write-Host "➡️  Redémarre la machine pour finaliser l'activation." -ForegroundColor Yellow

4 Diagnostic RDP Dépannage

Si RDP ne fonctionne pas malgré l'activation, lance ce script sur le PC cible pour identifier le problème.

Diagnostic_RDP.ps1 
# ============================================
# Diagnostic complet de l'état RDP
# À exécuter en PowerShell ADMIN sur le PC cible
# ============================================

Write-Host "=== Diagnostic RDP ===" -ForegroundColor Cyan

# 1. Registre
$ts = Get-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -ErrorAction SilentlyContinue
Write-Host "fDenyTSConnections : $($ts.fDenyTSConnections) (attendu: 0)"
Write-Host "fAllowToGetHelp    : $($ts.fAllowToGetHelp) (attendu: 1)"

# 2. Service
$svc = Get-Service TermService -ErrorAction SilentlyContinue
if ($svc) { Write-Host "TermService        : $($svc.Status) / $($svc.StartType)" }
else      { Write-Host "TermService        : INTROUVABLE ❌" -ForegroundColor Red }

# 3. Port 3389
$port = netstat -an | Select-String ":3389.*LISTENING"
if ($port) { Write-Host "Port 3389          : EN ÉCOUTE ✅" -ForegroundColor Green }
else       { Write-Host "Port 3389          : FERMÉ ❌"      -ForegroundColor Red }

# 4. Pare-feu
$fw = Get-NetFirewallRule -DisplayGroup "Bureau à distance" -ErrorAction SilentlyContinue |
      Where-Object { $_.Enabled -eq 'True' }
Write-Host "Règles pare-feu    : $($fw.Count) active(s)"

# 5. Info système
Write-Host ""
Write-Host "=== Système ===" -ForegroundColor Cyan
Write-Host "Hostname           : $env:COMPUTERNAME"
Write-Host "IP locale          : $((Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' } | Select-Object -First 1).IPAddress)"
Write-Host "Utilisateur        : $env:USERNAME"

Write-Host ""
Write-Host "Si tout est vert mais que la connexion échoue → redémarre." -ForegroundColor Yellow

5 Test depuis le PC admin Dépannage

Lance ce test depuis ton PC d'administration (remplace l'IP si besoin).

Test_Depuis_Admin.ps1 
# ============================================
# Test de connectivité vers un PC cible
# À exécuter depuis le PC d'administration
# ============================================

$target = "192.168.0.8"   # ← Modifie l'IP ici

Write-Host "=== Test vers $target ===" -ForegroundColor Cyan

# 1. Ping
Write-Host "`n[1] Ping..."
if (Test-Connection -ComputerName $target -Count 2 -Quiet) {
    Write-Host "    ✅ La machine répond au ping" -ForegroundColor Green
} else {
    Write-Host "    ❌ Pas de réponse au ping (pare-feu ou machine éteinte)" -ForegroundColor Red
}

# 2. Port RDP 3389
Write-Host "`n[2] Port RDP 3389..."
$rdp = Test-NetConnection -ComputerName $target -Port 3389 -WarningAction SilentlyContinue
if ($rdp.TcpTestSucceeded) {
    Write-Host "    ✅ Port 3389 ouvert → RDP devrait marcher" -ForegroundColor Green
} else {
    Write-Host "    ❌ Port 3389 fermé → vérifier activation RDP + pare-feu" -ForegroundColor Red
}

# 3. Port MSRA 135 (RPC)
Write-Host "`n[3] Port RPC 135 (nécessaire pour MSRA)..."
$rpc = Test-NetConnection -ComputerName $target -Port 135 -WarningAction SilentlyContinue
if ($rpc.TcpTestSucceeded) {
    Write-Host "    ✅ Port 135 ouvert → MSRA devrait marcher" -ForegroundColor Green
} else {
    Write-Host "    ❌ Port 135 fermé → vérifier activation MSRA + pare-feu" -ForegroundColor Red
}

Write-Host ""
Write-Host "=== Interprétation ===" -ForegroundColor Cyan
Write-Host "Ping KO          → machine éteinte ou sur un autre réseau"
Write-Host "Ping OK / RDP KO → lancer le script d'activation + redémarrer le PC cible"
Write-Host "Tout OK          → lancer la connexion depuis le dashboard"

6 Comment ça marche ?

  • Prise en main (RDP) : télécharge un fichier .rdp → Windows ouvre une session complète via mstsc.exe. Idéal quand personne n'est devant le PC (verrouille l'écran distant).
  • Assister le collègue (MSRA) : envoie une notification sur l'écran du collègue. Il clique sur Autoriser pour que tu puisses voir son écran et l'aider sans lui couper sa session.

Astuce : après avoir modifié le fichier .reg MSRA, pense à le re-fusionner sur ton PC admin (double-clic → Oui) sinon l'ancienne version reste active.
